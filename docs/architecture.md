# 架构与设计决策

写给要改引擎本体、或者想搞清楚「为什么它是这样」的人。使用方法见[入门](getting-started.md)与[教程](tutorial.md)。

## 核心不变量：第 N 帧只是 N 的函数

绘制不读上一帧、不累积任何状态。`drawFrame(ctx, n)` 给同一个 n，在**任何机器、任何浏览器、任何分片**上画出的画面逐字节相同。这一条不变量买来三件事：

| 买到什么 | 为什么 |
|---|---|
| **可平行渲染** | 每片区间独立，同时开几个浏览器实例，速度按片数上升 |
| **可跳帧** | 任意帧随时出静帧，QC 才可能做 |
| **可全量自检** | 不截图、只跑绘制，几秒把几千帧全过一遍查抛错 |

后面所有「看起来可以更方便但不做」的决定，都是在这条不变量面前让路的。

## 三层结构，依赖只向下

```
contract ← runtime ← host
```

| 层 | 在哪跑 | 内容 |
|---|---|---|
| `contract/` | 都不跑（纯数据与校验） | 配置校验、视口、时间轴数据与查询 |
| `runtime/` | 浏览器里 | 动效、绘制原语、内建件、镜头装配 |
| `host/` | Node 里 | CLI、渲染会话（CDP）、ffmpeg、自检、TTS 编排 |

硬规则：

- **`contract` 不许 import `runtime` 或 `host`；`runtime` 不许 import `host`。**
- **扩展名就是「在哪跑」。** `contract/` 与 `runtime/` 全部是 `.js`（它们会被打进**浏览器里跑的那一份**），
  `host/` 全部是 `.mjs`（**只在 Node 里跑**）。实测 14 / 35 / 30 个文件，**零例外**。
  好处是 `git ls-files 'src/**/*.mjs'` 一眼就是「Node 侧清单」，看扩展名就知道新文件该放哪一层。
- **`host` 不进公开面。** 镜头文件只 `import ... from 'filmwright'`（`src/index.js`），那上面导出的全部是浏览器里跑的东西。镜头 import 到 Node 侧的东西，会让库的内部结构和镜头耦合。
- **引擎不认识任何片子。** 配置、时间轴、镜头全部由 `boot()` 注入；引擎里没有一个具体片子的名字。

> 前两条由 `tests/structure.test.mjs` 钉住（扫全部 `src/` 源文件，带「扫到 0 个 / 解析到 0 条边即失败」的下限）。
> 在此之前它们**只有文档、没有判据** —— 分层「0 违例」是一次人工把 162 条边逐条归类得出的结论。

## 一次渲染的完整链路

```
film.config.mjs ──┐
script/timeline.json ──┼─→ boot() ─→ drawFrame(ctx, n) ─→ CDP 截图 ─→ ffmpeg
shots/index.js ──┘
```

`boot()`（`src/runtime/stage/index.js`）按固定顺序装配，顺序本身就是设计：

1. **装配置**（`install`，原地填充 `theme` / `fonts`，绘制模块 import 的是这两个对象本身，换引用绑定就失效了）；
2. **装时间轴**；
3. **等字体就绪**（字体没就绪就画，首帧会用回退字体，度量全错）；
4. **等素材加载完**（图片没加载完就画，canvas 什么都不画——不是报错，是一帧空白，只出现在前几帧，最难查）；
5. **求值镜头模块**（必须最后：见下一节）；
6. **串接区间 + 组装章节卡**。

然后宿主侧逐帧调用 `drawFrame(ctx, n)`：先画内建件（背景 / HUD / 字幕 / 章节卡 / 进度条），再画当前帧所在镜头的 `draw(ctx, n, t, accent)`，片尾区画署名卡并压黑。

## 镜头契约

```js
{
  start: cutBefore('S02'),              // 从哪一帧接管画面
  draw(ctx, n, t, accent) { ... },      // n 从 1 起；t = n / fps；accent 是本章主色
}
```

三条刻意的设计：

- **只声明 `start`，不写 `to`。** 区间由 `bindShots` 串接：下一个镜头的 `start - 1` 就是上一个镜头的末帧。手算 `from/to` 必然产生重叠或空隙；空隙不是静默画空帧，而是直接报错（`第 X–Y 帧没有镜头接管`）。
- **镜头文件在模块顶层就调 `cutBefore('S01')` 这类查询**——那正是它不写硬编码帧号的原因。而查询要求时间轴已装载，所以 `boot()` 收的是 `loadShots` **函数**而非已求值的模块，由引擎决定求值时机。这条踩过：先 import 镜头再装时间轴，会报「时间轴未装载就查询了 S01」。
- **`draw` 必须是普通函数**：镜头里会读 `this.from`（本镜头的起始帧），箭头函数会把 `this` 丢掉，每帧都抛错。示例项目用 `withDesign` 包装统一处理缩放与 `this`。

## 确定性从哪来

同一份镜头在不同浏览器、不同机器上渲染结果**逐像素相同**，靠的不是运气：

- Chrome 启动参数钉死 `--force-color-profile=srgb`。实测系统 Edge 与 Chrome-for-Testing 在**没有**这个参数时有 85% 像素差 1–8 级；钉死之后逐像素完全相同。
- `--headless=new`。渲染不依赖显示器——CI 与服务器上没有 X server，有头模式直接退出（实测报 `Missing X server or $DISPLAY`）；无头与有头走同一条渲染路径，抓基准验证过逐字节一致。
- `--disable-gpu`。宁可慢也要确定性，不追求 GPU 加速路径。
- 任何「随机」都来自确定性哈希（`rnd(seed)`），同一 seed 永远同一串。
- 时间轴是**数据**（`timeline.json`），不是代码；逐句配音有内容寻址缓存，改一句只重合成那一句。

## 刻意不做的事

每个都是权衡过的不做，不是没来得及做：

- **视频素材**：逐帧渲染要求「画第 N 帧时素材已就位」，而 video 元素是异步定位的——半吊子的 seek 直接破坏核心不变量。要用的画面先用 `ffmpeg -i b-roll.mp4 frames/%05d.png` 抽成图片序列，再按普通图片摆。
- **富文本排版**：`text()` 是 `fillText` 加字距、发光、描边、按宽缩字号；换行用 `wrap()`，不做段落排版引擎。
- **主题包机制**：换主题就是改 `theme` 的值，结构只有一套。
- **外挂字幕**：成片里字幕是**烧进画面**的（这是刻意的：观众不该能关掉它）。
  但要 SRT 有现成命令 —— `filmwright srt --project <目录>`（还支持 `--translation` 出双语轨）。
  （这一段原来写着"要 SRT 从 `timeline.json` 的 `subs` 自己导出"，已过期。）

完整清单与原因见 [LIMITATIONS](../LIMITATIONS.md)。

## 已经踩过的坑（写成代码防着）

| 坑 | 现在的防线 |
|---|---|
| 镜头顶层查询时时间轴未装载 | `boot()` 收 `loadShots` 函数，强制求值顺序 |
| 镜头区间手算出错 / 漏画 | 只声明 `start`，`bindShots` 串接 + 覆盖自检，漏一段直接报错 |
| `theme` 键写错，默认值变 `undefined` 一路传到绘制才崩 | 配置期校验每个键非空；`themeKeys` 静态检查运行时引用（见[质检](qc.md)） |
| `accents[3]` 越界（长度由使用者定） | 内部组件统一用 `accent(i)` 回绕；镜头用 `theme.accents[i]` 时自己保证长度 |
| 字体没就绪，首帧度量全错 | `boot()` 等 `document.fonts.ready` 才放行 |
| 图片没加载完，canvas 静默画空白 | `boot()` 等全部素材加载完；**图片加载失败是抛错**（字体失败才回退——该有的东西没了必须响） |
| 素材名笔误传成 `undefined` | `img()` / `picture()` 引用未声明的名字当场抛错，并列出可用名字 |
| 模块相对路径写错，页面**静默**不 ready | 静态检查 `imports` 逐文件验证相对路径存在 |
| `letterSpacing` 忘了复位，"MoonBit" 上屏成 "MoonB it" | `text()` 内部 save/restore，退出即还原 |
| 页面模块加载失败完全静默 | 渲染页把错误**画进画面**并记进 `window.__bootError` / `__lastError`，QC 不会把出错帧当正常帧 |
| CI 无显示器，有头浏览器直接退出 | 渲染会话一律无头启动（`--headless=new`），并验证过与有头逐像素一致 |
